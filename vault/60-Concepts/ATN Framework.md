# ATN Framework

The [[NIA-AA]] biological-definition framework for [[Alzheimer's Disease]]:

| Letter | Meaning | Plasma marker |
|---|---|---|
| **A** | Amyloid pathology | [[Aβ42-40]] |
| **T** | Tau pathology | [[p-tau-181]] |
| **N** | Neurodegeneration | [[NfL]] |

Some extended versions add **I** (inflammation), where [[GFAP]] would sit.
