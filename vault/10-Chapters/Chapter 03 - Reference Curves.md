# Chapter 3 — Age-Specific Reference Curves

Continuous reference curves (an upgrade from the discrete bins of [[Chapter 02 - Reference Intervals]]) using [[GAMLSS]]/[[LMS]] modelling.

## Cohort & methods

- Cohort: [[CHMS]] — expanded analysis
- Modelling: [[Reference Curve Modelling]] via GAMLSS / LMS frameworks
- Analytes: [[Aβ42-40]], [[p-tau-181]], [[NfL]], [[GFAP]]
- Health-variable associations explored (see Appendix 4)

## Outputs

- Continuous percentile curves for each analyte vs. age
- A web application for interpreting individual results (Appendix 5)
- Associations of biomarkers with clinical and demographic variables

- Used to phenotype resilience in [[Chapter 05 - Cognitive Resilience]]
