# LMS — Lambda-Mu-Sigma

Classical method for fitting smooth percentile reference curves (Cole, 1988). A precursor and special case of [[GAMLSS]]; both are used for [[Reference Curve Modelling]] in [[Chapter 03 - Reference Curves]].
