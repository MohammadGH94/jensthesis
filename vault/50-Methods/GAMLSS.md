# GAMLSS

Generalized Additive Models for Location, Scale and Shape — flexible regression framework that handles non-Gaussian response distributions. The primary engine for the continuous reference curves in [[Chapter 03 - Reference Curves]]. See [[Reference Curve Modelling]] for context, and [[LMS]] for the classical antecedent.
